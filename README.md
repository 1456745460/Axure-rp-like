# 在线原型设计（Axure-like）

基于 **Vite 3 + Vue 3 + Element Plus** 的浏览器端原型设计工具。

## 功能

- **左上**：页面 / 文件夹目录树（增删改查、重命名、切换页面）
- **左下**：可拖拽的 Element Plus 风格组件库
- **画布**：点阵背景，支持真实组件拖动影像、居中拖入、框选/多选、整组移动、缩放、边缘和中心对齐提示、双击就地编辑
- **表格**：直接编辑表头和单元格，每行右侧增删按钮；拖动列边线调整相邻列宽，拖动最右线调整表格总宽
- **组件**：包含分页、日期/时间选择、Alert、Dialog、Loading、Message 和 MessageBox 等 Element Plus 风格控件
- **图片**：拖入本地图片或粘贴剪贴板图片，自动保存为图片控件和 base64 数据
- **目录与面板**：页面/文件夹拖拽排序和移动，页面目录、组件库、属性面板均可折叠
- **预览**：无需保存或导出，即可在新标签页查看所有页面；跟随当前编辑器的画布修改自动更新，刷新浏览器也会读取最新本地草稿
- **保存**：每次操作结束后 500ms 自动保存到 Express + SQLite（sql.js / WASM）；本地草稿可恢复，失败后保留内容供重试，仍可手动保存
- **导出**：单文件 HTML，多页时左侧为可折叠目录菜单树，预览页同样支持收起菜单，可离线打开

## 启动

```bash
npm install
npm run dev
```

- 前端：http://127.0.0.1:5173  
- 后端 API：http://127.0.0.1:3789  
- SQLite 文件：`data/prototype.db`

也可分别启动：

```bash
npm run server   # 仅 API
npm run client   # 仅 Vite
```

## 使用提示

1. 从左下组件库拖拽组件到画布
2. 选中组件后可在右侧改属性与样式
3. 右侧输入表头时使用逗号增删列，失焦后应用；画布内可直接输入表头与数据。拖动表格右上角「⠿」移动整个表格；标签页、下拉选项和步骤项目使用回车分行
4. 双击组件或选中后按 `Enter`，在画布上直接编辑；`Esc` 取消编辑或取消选择。表格无需双击
5. `Delete/Backspace` 删除，方向键移动 1px，`Shift + 方向键` 移动 10px
6. 在空白画布按住鼠标拖出选框，或 `Shift/Ctrl/Cmd + 单击` 多选；`Ctrl/Cmd + A` 全选当前页。`Ctrl/Cmd + C/X/V` 复制/剪切/粘贴所选控件或粘贴外部图片；粘贴组的中心位于最近的画布鼠标位置（边缘自动限制）；`Ctrl/Cmd + D` 快速复制，`Ctrl/Cmd + S` 保存
7. `Ctrl/Cmd + Z` 撤销，`Ctrl/Cmd + Shift + Z` 或 `Ctrl + Y` 重做；拖动/缩放/目录拖拽各作为一步，最多保留 60 步；打开或新建项目会清空历史
8. `Ctrl/Cmd + B/I/U` 切换选中控件的加粗、倾斜、下划线；输入框内保留浏览器原生文字编辑快捷键
9. 顶部显示自动保存状态，失败时可点「保存」重试；「预览」打开新标签页，「导出 HTML」下载可离线预览的原型
